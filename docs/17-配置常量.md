# ⚙️ 配置常量

**config/settings.py 详细说明**

---

## 📋 模块概述

settings.py 包含项目的全局配置常量，包括版本信息、颜色定义、状态标记等。

---

## 📌 版本信息

```python

# 应用名称

# 应用标题
APP_TITLE = f"{APP_NAME} v{APP_VERSION}"
```

## 📝 使用示例

### 导入常量

```python
from config.settings import (
    APP_VERSION,
    UI_COLORS,
    EXCEL_COLORS,
    COMPARE_STATUS,
    OPERATOR_MAP,
    KEY_COLUMN,
    DEFAULT_FORMULA,
)
```

### 使用颜色

```python
# UI中使用
label.setStyleSheet(f"color: {UI_COLORS['text_primary']};")

# Excel导出中使用
from openpyxl.styles import PatternFill
fill = PatternFill(
    fill_type="solid",
    start_color=EXCEL_COLORS["match"]
)
```

### 使用状态

```python
def get_status_text(status_type):
    symbol = COMPARE_STATUS.get(status_type, "?")
    desc = STATUS_DESCRIPTIONS.get(status_type, "未知")
    return f"{symbol} {desc}"
```
