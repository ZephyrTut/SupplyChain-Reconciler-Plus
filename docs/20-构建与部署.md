## 🔧 开发环境搭建

### 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 操作系统 | Windows 10 / macOS 10.14 / Ubuntu 20.04 | 最新版本 |
| Python | 3.10 | 3.11 或 3.12 |
| 内存 | 2GB | 4GB+ |
| 磁盘 | 500MB | 1GB+ |

### 1. 安装Python

#### Windows
```bash
# 从 https://www.python.org/downloads/ 下载
# 或使用 conda
conda create -n reconciler python=3.11
conda activate reconciler
```

#### macOS
```bash
# 使用 Homebrew
brew install python@3.11

# 或使用 conda
conda create -n reconciler python=3.11
conda activate reconciler
```

#### Linux
```bash
# Ubuntu/Debian
sudo apt-get install python3.11 python3.11-venv python3.11-dev

# Fedora
sudo dnf install python3.11 python3.11-devel
```

### 2. 克隆项目

```bash
# 使用 Git
### GitHub Actions 自动发布（Windows）

项目包含自动发布工作流：

- 文件：`.github/workflows/release-windows.yml`
- 触发：推送 `v*` 标签或手动 `workflow_dispatch`

特性：

1. **失败自动重试**
  - 依赖安装：最多 3 次
  - PyInstaller 构建：最多 2 次

2. **构建产物校验**
  - 检查 exe 是否存在且大小合理
  - 生成 SHA256 校验文件（`.sha256`）
  - 校验 hash 文件格式

3. **Release 附件命名规范化**
  - `SupplyChain-Reconciler-Plus-vX.Y.Z-windows-x64.7z`
  - `SupplyChain-Reconciler-Plus-vX.Y.Z-windows-x64.sha256`

4. **体积优化策略**
  - 使用 `UPX` 压缩可执行文件
  - 打包格式优先使用 `7z -mx=9`（高压缩比）
  - Release 默认仅上传高压缩包与校验文件

### Releases 迁移到 Gitee

项目包含迁移工作流：

- 文件：`.github/workflows/sync-releases-to-gitee.yml`
- 触发：手动 `workflow_dispatch`

必填 Secrets：

- `GITEE_OWNER`
- `GITEE_REPO`
- `GITEE_TOKEN`

可选输入：

- `tag`：仅同步指定标签
- `limit`：批量同步数量上限（默认 20）
- `source_repo`：源 GitHub 仓库（默认当前仓库）

git clone https://github.com/your-org/SupplyChain-Reconciler-Plus.git
cd SupplyChain-Reconciler-Plus

# 或者下载 ZIP
# 然后解压到项目目录
```

### 3. 创建虚拟环境

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```


```bash

python main.py
```

## 📦 打包与发布

### 方式1: PyInstaller (生成独立可执行文件)

#### 安装 PyInstaller

```bash
pip install pyinstaller
```

#### 构建可执行文件

```bash
# Windows - 生成 exe
pyinstaller --onefile --windowed \
  --name "SupplyChain-Reconciler-Plus" \
  --icon=assets/icon.ico \
  main.py

# macOS - 生成 app
pyinstaller --onefile --windowed \
  --name "SupplyChain-Reconciler-Plus" \
  --icon=assets/icon.icns \
  main.py

# Linux - 生成可执行文件
pyinstaller --onefile \
  --name "SupplyChain-Reconciler-Plus" \
  main.py
```

**输出位置**: `dist/` 目录

#### 生成的文件

| 平台 | 输出文件 | 大小 |
|------|---------|------|
| Windows | SupplyChain-Reconciler-Plus.exe | ~150MB |
| macOS | SupplyChain-Reconciler-Plus.app | ~200MB |
| Linux | SupplyChain-Reconciler-Plus | ~150MB |

### 方式2: 创建安装程序

#### Windows - 使用 NSIS

```bash
# 安装 NSIS (https://nsis.sourceforge.io/)
# 创建 installer.nsi 脚本

# 编译安装程序
makensis installer.nsi

# 输出: SupplyChain-Reconciler-Plus-Setup.exe
```

#### macOS - 创建 DMG

```bash
# 使用 dmgbuild
pip install dmgbuild

dmgbuild -s settings.py "SupplyChain-Reconciler-Plus" output.dmg
```

### 方式3: Docker 容器化（可选）

```dockerfile
# 创建 Dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install -r requirements.txt

COPY . .

CMD ["python", "main.py"]
```

```bash
# 构建镜像
docker build -t reconciler:1.4.3 .

# 运行容器
docker run -it reconciler:1.4.3
```

## 🌍 生产部署

### 部署场景1: 单机部署

```bash
# 1. 解压应用
unzip SupplyChain-Reconciler-Plus-v1.4.3.zip
cd SupplyChain-Reconciler-Plus

# 2. 安装依赖
pip install -r requirements.txt

# 3. 创建配置目录
mkdir -p ~/.config/SupplyChain-Reconciler-Plus

# 4. 启动应用
python main.py
```

### 部署场景2: 批量部署（企业）

#### 使用 Group Policy (Windows)

```batch
@echo off
REM 企业部署脚本

set INSTALL_DIR=C:\Program Files\SupplyChain-Reconciler-Plus
set SOURCE_DIR=\\network\share\reconciler

REM 复制文件
xcopy "%SOURCE_DIR%\*" "%INSTALL_DIR%\" /E /I /Y

REM 创建快捷方式
powershell -Command "
$WshShell = New-Object -ComObject WScript.Shell
$Shortcut = $WshShell.CreateShortcut('$env:APPDATA\Microsoft\Windows\Start Menu\Programs\SupplyChain-Reconciler.lnk')
$Shortcut.TargetPath = '%INSTALL_DIR%\SupplyChain-Reconciler-Plus.exe'
$Shortcut.Save()
"

echo 部署完成
```

#### 使用 Ansible (Linux)

```yaml
---
- name: Deploy SupplyChain-Reconciler-Plus
  hosts: all
  vars:
    app_version: "1.4.3"
    install_dir: "/opt/reconciler"
  
  tasks:
    - name: Create install directory
      file:
        path: "{{ install_dir }}"
        state: directory
        mode: '0755'
    
    - name: Download and extract
      unarchive:
        src: "https://github.com/your-org/releases/v{{ app_version }}/app.tar.gz"
        dest: "{{ install_dir }}"
        remote_src: yes
    
    - name: Install dependencies
      pip:
        requirements: "{{ install_dir }}/requirements.txt"
        virtualenv: "{{ install_dir }}/venv"
    
    - name: Create systemd service
      template:
        src: reconciler.service.j2
        dest: /etc/systemd/system/reconciler.service
      notify: start reconciler
    
    - name: Enable service
      systemd:
        name: reconciler
        enabled: yes
        daemon_reload: yes
```

## 🆘 故障排查

### 常见问题

#### 1. Python 找不到

```bash
# Windows
python -m pip --version

# 确保 Python 在 PATH 中
echo %PATH%
```

#### 2. 依赖安装失败

```bash
# 升级 pip
pip install --upgrade pip

# 清除缓存
pip install --no-cache-dir -r requirements.txt
```

#### 3. 应用启动失败

```bash
# 检查 Python 版本
python --version

# 运行诊断
python -c "import config.settings; print('OK')"
```

#### 4. PyQt6 相关错误

```bash
# 重新安装 PyQt6
pip uninstall PyQt6 -y
pip install PyQt6>=6.0.0
```
