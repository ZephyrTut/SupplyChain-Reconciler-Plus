# 🧹 数据清洗

**去中文清洗与关键词保留**

---

## 📋 功能概述

数据清洗用于在对账前预处理数据，解决两表数据格式不一致的问题。

### 常见清洗场景

| 场景 | 原始值 | 清洗后 |
|------|--------|--------|
| 仅保留中文订单号 | `订单A001` | `A001` |
| 关键词保留 | `换单A01`（关键词=换单） | `换单A01` |
| 全中文备注 | `全中文备注` | `全中文备注` |

---

## 🎨 界面说明

### 数据清洗区域

```
┌─────────────────────────────────────────────────────────────┐
│ 🧹 数据清洗                                      [➕ 添加]  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  列: [到货单号 ▼]   去中文 [☑]   保留关键词: [换单,返修]    │
│                                                             │
│  💡 全中文会自动保留，命中关键词也会保留                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 界面元素

| 元素 | 说明 |
|------|------|
| 列下拉框 | 选择要清洗的列 |
| 去中文 | 去除中文字符（基础能力） |
| 保留关键词 | 命中关键词的内容将保留 |
| ✕ 按钮 | 删除该清洗规则 |
| ➕ 添加 | 添加新的清洗规则 |

---

## 📝 去中文（保留关键词）

规则：
- **全中文**：原样保留
- **包含关键词**：原样保留
- 其他情况：去除中文字符

示例：
- `换单A01`（关键词=换单）→ `换单A01`
- `全中文备注` → `全中文备注`
- `订单A001` → `A001`

---

## 📝 配置示例

```
列: 备注
去中文: 勾选
保留关键词: 换单,返修
```

---

## ⚠️ 注意事项

- 清洗是**不可逆**操作，原始数据仅在内存中被修改
- 建议用「导出预处理预览」确认效果

---

## 💻 技术实现

### 配置数据格式

```python
clean_rules = [
    {
        "column": "备注",
        "mode": "去中文保留关键词",
        "keywords": ["换单", "返修"]
    }
]
```
