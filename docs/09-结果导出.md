# 📥 结果导出

**Excel导出与颜色标记详解**

---

## 📋 功能概述

对账完成后，可将结果导出为带颜色标记的Excel文件，方便查看和分享。

### 导出特性

- ✅ 多Sheet结构
- ✅ 行颜色标记
- ✅ 自动列宽
- ✅ 统计信息

## 📁 导出文件结构

### 文件命名

```
对账结果_YYYYMMDD_HHMMSS.xlsx

示例: 对账结果_20260111_143052.xlsx
```

### Sheet结构

| Sheet名 | 内容 | 说明 |
|---------|------|------|
| 📋 完整结果 | 所有数据 | 包含一致、差异、缺失 |
| 📌 差异数据 | 仅差异和缺失 | 便于快速查看问题 |
| ℹ️ 说明 | 元数据信息 | 配置、统计、图例 |

---

## 🎨 颜色标记

### 行颜色规则

| 状态 | 颜色 | RGB值 | 说明 |
|------|------|-------|------|
| ✓ 一致 | 浅绿色 | #D1FAE5 | 数量完全匹配 |
| ↕ 差异(正) | 浅黄绿 | #D9F99D | 手工 > 系统 |
| ↕ 差异(负) | 浅蓝色 | #BFDBFE | 手工 < 系统 |
| ✗ 缺失 | 浅红色 | #FECACA | 单方存在 |

### 表头样式

- 背景色: 浅灰色 (#E2E8F0)
- 字体: 加粗
- 对齐: 居中

## 📊 列顺序

导出的列按以下顺序排列：

| 序号 | 列名 | 说明 |
|------|------|------|
| 1 | __KEY__ | 复合主键 |
| 2~N | 透视列 | 按字母排序 |
| N+1 | 系统总计 | 系统表总计 |
| N+2 | 手工数量 | 手工表数量 |
| N+3 | 差值 | 计算的差值 |
| N+4 | 比对状态 | 状态符号 |

### 示例

```
| __KEY__ | 已完成 | 处理中 | 系统总计 | 手工数量 | 差值 | 比对状态 |
```

## 📥 导出步骤

### 步骤1: 执行对账

确保已完成对账，结果预览显示数据。

### 步骤2: 点击导出

点击「📥 导出Excel」按钮。

### 步骤3: 选择保存位置

1. 弹出文件保存对话框
2. 选择保存目录
3. 可修改文件名
4. 点击「保存」

### 步骤4: 完成

- 显示导出成功提示
- 可选择直接打开文件

---

## 🔧 自动列宽

系统会根据内容自动调整列宽：

| 列类型 | 宽度规则 |
|--------|---------|
| __KEY__ | 最小15字符，最大50字符 |
| 数值列 | 最小10字符 |
| 状态列 | 固定12字符 |
| 其他 | 根据内容自适应 |

## 📊 导出预处理预览

### 功能

在执行对账前，可单独导出预处理后的数据预览：

1. **手工表预处理预览**: 显示清洗、筛选、透视后的手工表
2. **系统表预处理预览**: 显示筛选、透视后的系统表（含零件号自动映射统计）

### 用途

- 检查数据清洗效果
- 验证筛选条件
- 确认透视计算
- 查看系统零件号自动映射统计

### 操作

在步骤2的样例区域：
- 点击「导出手工表预处理预览」
- 点击「导出系统表预处理预览」

## ⚠️ 注意事项

### 1. 文件被占用

如果目标文件已打开，导出会失败。

**解决**: 关闭Excel后重试。

### 2. 磁盘空间

确保目标磁盘有足够空间。

### 3. 文件名限制

避免使用特殊字符：`\ / : * ? " < > |`

### 4. 大文件性能

数据量超过10万行时：
- 导出时间较长
- 建议分批处理

## 💻 技术实现

### 核心函数

```python
from core.export_engine import ExportEngine

ExportEngine.export_results(
    out_path="对账结果.xlsx",
    result_df=result_dataframe,
    pivot_values=["已完成", "处理中"],
    config_info={
        "manual_file": "手工表.xlsx",
        "system_file": "系统表.xlsx",
        "key_mappings": [...],
        "formula": "手工数量 - 系统总计"
    }
)
```

### 颜色应用

```python
from openpyxl.styles import PatternFill

# 定义颜色
COLORS = {
    "match": "FFD1FAE5",     # 一致-绿
    "diff_pos": "FFD9F99D",  # 差异-黄
    "diff_neg": "FFBFDBFE",  # 差异-蓝
    "missing": "FFFECACA",   # 缺失-红
}

# 应用填充
fill = PatternFill(fill_type="solid", start_color=color)
cell.fill = fill
```
