## 📦 安装步骤

### 1. 克隆项目

```bash
git clone https://github.com/yourusername/SupplyChain-Reconciler-Plus.git
cd SupplyChain-Reconciler-Plus
```

### 2. 创建虚拟环境（推荐）

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 验证安装

```bash
python main.py
```

如果看到应用窗口正常启动，说明安装成功。

## 🔧 常见安装问题

### 问题1: PyQt6 安装失败

**症状**: `pip install PyQt6` 报错

**解决方案**:
```bash
# 升级pip
pip install --upgrade pip

# 使用国内镜像
pip install PyQt6 -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题2: qt-material 主题不生效

**症状**: 界面显示为默认灰色

**解决方案**:
1. 确认 qt-material 已安装
2. 检查控制台是否有 `qt-material 主题已加载` 提示
3. 重新安装: `pip install --force-reinstall qt-material`

### 问题3: Excel文件无法读取

**症状**: 导入Excel报错

**解决方案**:
```bash
# 重新安装Excel库
pip install --force-reinstall openpyxl xlrd
```

### 问题4: Windows下pywin32报错

**症状**: 活动Excel检测功能不可用

**解决方案**:
```bash
pip install pywin32
# 运行安装后脚本
python -m pywin32_postinstall -install
```

## 📋 环境检查脚本

创建 `check_env.py` 检查环境:

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""环境检查脚本"""

import sys

def check():
    print("=" * 50)
    print("SupplyChain-Reconciler-Plus 环境检查")
    print("=" * 50)
    
    # Python版本
    py_ver = sys.version_info
    print(f"\n[Python] {py_ver.major}.{py_ver.minor}.{py_ver.micro}", end=" ")
    if py_ver >= (3, 10):
        print("✅")
    else:
        print("❌ 需要 3.10+")
    
    # 必需依赖
    deps = [
        ("pandas", "1.5.0"),
        ("openpyxl", "3.0.0"),
        ("xlrd", "2.0.0"),
        ("PyQt6", "6.0.0"),
        ("qt_material", "2.14"),
    ]
    
    print("\n[依赖检查]")
    for name, min_ver in deps:
        try:
            mod = __import__(name.replace("-", "_"))
            ver = getattr(mod, "__version__", "unknown")
            print(f"  {name}: {ver} ✅")
        except ImportError:
            print(f"  {name}: 未安装 ❌")
    
    # 可选依赖
    print("\n[可选依赖]")
    try:
        import win32com
        print("  pywin32: 已安装 ✅")
    except ImportError:
        print("  pywin32: 未安装 (可选)")
    
    print("\n" + "=" * 50)

if __name__ == "__main__":
    check()
```

运行: `python check_env.py`
