# ⚙️ 配置面板

**QtConfigPanel 详细说明**

---

## 📋 面板概述

配置面板是步骤2的核心组件，包含所有对账规则配置。

### 可折叠区域

面板由多个可折叠的配置区组成，支持展开/折叠操作。

## 📑 主键映射区

### 界面布局

```
┌─────────────────────────────────────────────────────────────────────────┐
│ ▼ 📑 主键映射 (必填)                                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  映射1: 手工表列 [订单编号 ▼]  ↔  系统表列 [订单号 ▼]    [➕] [➖]       │
│  映射2: 手工表列 [物料编码 ▼]  ↔  系统表列 [零件号 ▼]    [➕] [➖]       │
│                                                                         │
│                                    [+ 添加映射]                          │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 组件说明

| 组件 | 类型 | 说明 |
|------|------|------|
| 手工表列下拉框 | QComboBox | 选择手工表的主键列 |
| 系统表列下拉框 | QComboBox | 选择系统表的对应列 |
| 添加按钮 | QPushButton | 添加新映射行 |
| 删除按钮 | QPushButton | 删除当前映射行 |

### 操作流程

1. 点击手工表列下拉框选择列
2. 点击系统表列下拉框选择对应列
3. 如需多字段主键，点击「+ 添加映射」

## 🔍 筛选条件区

### 界面布局

```
┌─────────────────────────────────────────────────────────────────────────┐
│ ▼ 🔍 筛选条件 (可选)                                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  手工表筛选:                                                            │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ [状态 ▼] [等于 ▼] [已审核        ]                   [➖]       │   │
│  │ [类型 ▼] [包含于 ▼] [正常,补货   ]                   [➖]       │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                    [+ 添加筛选]                          │
│                                                                         │
│  系统表筛选:                                                            │
│  ┌─────────────────────────────────────────────────────────────────┐   │
│  │ [执行状态 ▼] [不等于 ▼] [已取消      ]               [➖]       │   │
│  └─────────────────────────────────────────────────────────────────┘   │
│                                    [+ 添加筛选]                          │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 操作符说明

| 操作符 | 值格式 | 说明 |
|--------|--------|------|
| 等于 | 单值 | `状态 = 已审核` |
| 不等于 | 单值 | `状态 ≠ 已取消` |
| 包含 | 单/多值 | 列值包含输入值 |
| 不包含 | 单/多值 | 列值不包含输入值 |
| 包含于 | 多值(逗号分隔) | `已完成,已发货` |
| 大于 | 数值 | `数量 > 0` |
| 小于 | 数值 | `数量 < 1000` |

> 系统表筛选中，选择列后若操作符为「等于/不等于/包含于/不包含于」，值会自动从该列唯一值中加载（例如任务状态：已入库、部分入库等）。
>
> 当「包含于/不包含于」可选值较多时，行内显示为紧凑摘要，点击「选择...」会弹出大尺寸可搜索选择窗，不会挤压主布局。
>
> 新增「例外保留」区域：主筛选按 AND，例外保留按 OR，最终为 `主筛选 OR 例外保留`。

## 🔁 系统零件号自动映射 (可选)

用于将系统表中的 `-000` 零件号，按手工表后缀映射为 `-001/-002...`。

### 适用场景

- 系统表零件号固定为 `-000`
- 手工表零件号包含真实后缀（如 `-001`）
- 需要以供应商 + 订单号 + 零件号前缀作为匹配依据

### 配置项

| 配置项 | 说明 |
|--------|------|
| 启用自动映射 | 勾选后生效 |
| 供应商列/订单列/零件列 | 系统表与手工表各自选择 |
| 后缀列表 | 逗号分隔，如 `-001,-002` |
| 映射统计 | 显示候选/匹配/歧义/未匹配行数 |

### 说明

- 仅当系统表零件号以 `-000` 结尾时参与映射
- 若同一组键出现多个后缀，视为歧义，不会自动替换
- 未匹配到后缀时保持原值

| 特性 | 手工表透视 | 系统表透视 |

| 配置 | 选出库值+入库值 | 选透视列 |

### 折叠区域实现

```python
class CollapsibleSection(QWidget):
    def __init__(self, title, parent=None):
        super().__init__(parent)
        self.toggle_button = QPushButton(f"▼ {title}")
        self.content = QWidget()
        self.toggle_button.clicked.connect(self._toggle)
    
    def _toggle(self):
        self.content.setVisible(not self.content.isVisible())
        icon = "▼" if self.content.isVisible() else "▶"
        self.toggle_button.setText(f"{icon} {self.title}")
```

### NoScrollComboBox

禁用滚轮的下拉框，避免影响外部滚动：

```python
class NoScrollComboBox(QComboBox):
    def wheelEvent(self, event):
        event.ignore()  # 忽略滚轮事件
```
